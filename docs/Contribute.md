# Contributing Examples
## When adding a new example:
1. Explain what the example demonstrates.
2. Include the required commands or Python code.
3. Identify any system dependencies.
4. Use realistic but clearly identified sample output.
5. Explain permission requirements.
6. Distinguish implemented functionality from planned functionality.
7. Avoid exposing secrets, host-specific paths, or sensitive process data.
8. Report Bugs and try to fix them
